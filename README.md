# Portafolio — Diego Cortes

Sitio portafolio construido con [Astro](https://astro.build) que presenta mis proyectos públicos de GitHub.

## Stack

- [Astro](https://astro.build) (sitio estático, cero JS por defecto)
- CSS puro, sin dependencias extra de frontend

## Proyectos destacados

| Proyecto | Stack | Descripción |
|---|---|---|
| [Hackadisc2026](https://github.com/DiegoCortes07/Hackadisc2026) | Python/FastAPI, Next.js, SQLite | Dashboard de ventas con KPIs, metas, pronósticos y CI |
| [Backend-Ayudantia-DSM](https://github.com/DiegoCortes07/Backend-Ayudantia-DSM) | Node/Express, Sequelize, Socket.IO | Backend educativo con auth, migraciones y tiempo real |
| [Proyecto-Rayman-5](https://github.com/DiegoCortes07/Proyecto-Rayman-5) | Unity, C# | Experiencia de Realidad Aumentada |
| [ProyectoIngSoftware2025-1](https://github.com/DiegoCortes07/ProyectoIngSoftware2025-1) | PHP | Proyecto del curso de Ingeniería de Software |
| [vite-project](https://github.com/DiegoCortes07/vite-project) | React, Vite | Calculadora web |

## Desarrollo

```bash
npm install
npm run dev
```

## Deploy

El despliegue a **GitHub Pages** es automático en cada push a `main` vía
`.github/workflows/deploy.yml`. El sitio queda en:

https://diegocortes07.github.io/portfolio/
